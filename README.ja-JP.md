# Process Scheduling
[英語版 (English)](./README.md)

![Cover image](GameJamSubmission/CoverImage.png)

「Process Scheduling」は、オペレーティングシステム（OS）のプロセススケジューラとなり、決められた時間内に各種コンピュータプロセスをCPUへどのように割り当てて処理するかを決定するゲームです。<br/>
ユーザーが実行するさまざまなプログラムをOSがどのように管理しているのか、その基本的な仕組みを体験してもらうように、このゲームを作成してみました。

OSにおけるプロセススケジューリングの基本概念をシンプルなゲームにするというアイデアのプロトタイプです。

2021年1月1日〜2021年2月1日に開催された[「Finally Finish Something game jam (FFSjam) 2021」ゲームジャム](https://itch.io/jam/finally-finish-something-2021)への提出作品として制作しました。

本ゲームは、[Unity](https://unity.com)ゲームエンジンとC#で作られています。

ゲームは[こちら](https://jayzonty.itch.io/process-scheduling)からブラウザ上でプレイできます。
